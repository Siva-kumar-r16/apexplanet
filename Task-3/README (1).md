# 🧪 The Sheldonverse

This project is part of my **45-Day Web Development Internship at ApexPlanet Software Pvt. Ltd.**

**The Sheldonverse** is an interactive website inspired by *The Big Bang Theory* and *Young Sheldon*, built using HTML, CSS, and JavaScript.

### ✨ Features
- 🎭 **Character Explorer:** Browse characters and actors with search and filtering.
- 📺 **Episode Explorer:** Explore show details and episodes with season filters.
- 🧠 **Interactive Quiz:** Discover which character matches your personality.
- ⭐ **Favorites Collection:** Save favorite characters using localStorage.
- 📱 **Responsive Design:** Supports desktop, tablet, and mobile devices.

### 🔌 API Integration
- **TVMaze Show Search API:** Retrieves television show details.
- **TVMaze Cast API:** Fetches cast members, actor names, and character information.
- **TVMaze Episodes API:** Retrieves episode titles, season numbers, air dates, summaries, and available images.

API data is fetched dynamically using JavaScript's **Fetch API** and `async/await`.

🔗 **API Documentation:** https://www.tvmaze.com/api

### 🛠️ Built With
HTML5 • CSS3 • JavaScript • TVMaze API • LocalStorage
