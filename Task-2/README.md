# 🤠 The Outlaw's Journal

This project is part of my **45-Day Web Development Internship at ApexPlanet Software Pvt. Ltd.**

For **Task 2: Intermediate HTML, CSS, and JavaScript**, I created *The Outlaw's Journal*, a Red Dead Redemption 2 inspired digital diary based on Arthur Morgan's journal, featuring a cinematic Western theme and interactive productivity tools.

### 🛠️ Built With
HTML • CSS • JavaScript • LocalStorage

### ✨ Features
- Personal diary with create, edit, delete, and search functionality
- Sketchbook gallery for uploading and managing images
- Daily Missions task manager
- Memories timeline
- Contact form with JavaScript validation
- Responsive design using Flexbox and CSS Grid
- LocalStorage for saving entries, tasks, and sketches
